# Царь горы — Unity 3D

Отдельная реализация GDD для Unity **2022.3.62f3 LTS**, C#, URP **14.0.11**, Windows x64. Браузерная версия в корне репозитория независима от этого проекта.

## Запуск по шагам

1. Установите **Unity Hub** с официального сайта Unity. Войдите в аккаунт и активируйте подходящую лицензию (например, Personal, если вы соответствуете её условиям).
2. Установите редактор **2022.3.62f3** через архив Unity. Если проект уже открыт в f1, закройте редактор и в Unity Hub выберите для проекта версию **2022.3.62f3**. Ранее собранные exe нужно пересобрать новым редактором. Для сборки Windows добавьте доступный для вашей ОС модуль **Windows Build Support**. Если будете собирать с IL2CPP, нужен соответствующий модуль и инструменты C++.
3. Скачайте репозиторий с GitHub: **Code → Download ZIP**, распакуйте архив.
4. В Unity Hub нажмите **Add → Add project from disk**. Выберите именно папку **MyGame-main/Unity**, где лежат `Assets`, `Packages`, `ProjectSettings`.
5. Откройте проект. Дождитесь установки URP и окончания импорта/компиляции. Для первоначальной установки пакетов требуется Интернет.
6. Подготовка проекта выполнится автоматически. Если сцена не открылась, выберите **Winter Yard → Prepare project**. Затем откройте `Assets/KingOfTheHill/Scenes/WinterYard.unity`.
7. Нажмите **Play** сверху редактора, перейдите во вкладку **Game**, нажмите **«ВЫЙТИ ВО ДВОР»**. Для полноэкранного вида Game можно использовать Maximize On Play.

Двор создаётся при запуске сцены. Пустой вид сцены до нажатия Play — ожидаемое поведение. Скрипт подготовки создаёт URP-ресурсы в `Assets/KingOfTheHill/Rendering`, назначает рендеринг и включает стартовую сцену в сборку. Он сохраняет существующий рендеринг, если вы уже назначили свой.

## Управление

- **WASD** — движение относительно камеры; **мышь** — обзор и направление атаки.
- **Space** — прыжок, **Shift** — рывок с перезарядкой 3 с.
- **ЛКМ** — толчок перед собой, перезарядка 0,8 с.
- **ПКМ** — бросить снежок по дуге. **E** рядом с одним из четырёх сугробов — пополнить запас (один снежок).
- **Esc** — пауза и освобождение курсора. Потеря фокуса во время матча тоже ставит игру на паузу.

## Что реализовано

Объёмный двор с четырьмя домами, тёплыми окнами и фонарями, лавочками, снеговиком и снегопадом. Физическая гора с ледяной площадкой, игрок и три бота, камера от третьего лица с проверкой препятствий, физическое отбрасывание, оглушение, прыжок, рывок и снежки. Удержание вершины приносит 1 очко в секунду; в воздухе и при оглушении очки не идут. Очки после падения сохраняются. Цель — 20/30/60 очков, меню сложности, громкость и чувствительность, пауза, результаты и повторный матч. Победы хранятся через PlayerPrefs, звуки синтезируются без сторонних ассетов.

## Сборка Windows

Выберите **Winter Yard → Build Windows x64**. Результат при успешной сборке: `Builds/Windows/KingOfTheHill.exe`. Для передачи игры архивируйте **всю** папку `Builds/Windows`, включая папку данных и DLL, а не только exe.

Альтернатива — **File → Build Settings → PC, Mac & Linux Standalone → Windows → x86_64**, затем **Build**. Если Unity предложит переключить платформу, дождитесь окончания импорта.

Автоматизированная сборка на машине с установленным и лицензированным редактором и модулем Windows:

```text
Unity -batchmode -quit -projectPath "<путь к MyGame/Unity>" -executeMethod WinterYardEditor.ProjectSetup.BuildWindows -logFile "<путь к build.log>"
```

На Windows используйте полный путь к `Unity.exe`. Не запускайте второй экземпляр редактора на уже открытом проекте. `WINTER_YARD_BUILD_PATH` может задавать другой путь вывода с именем exe.

## Проверка первого запуска

Проверьте отсутствие красных ошибок в Console, затем: меню → отсчёт → движение и обзор → прыжок → удар по боту → бросок и подбор снежка → накопление очков на вершине → победа/поражение → повторный матч. Проверьте Esc и возврат в меню. Отдельно проверьте собранный exe.

## Статус проверки и ограничения

В облачной среде Unity Editor и лицензия отсутствуют: **проект не компилировался и не запускался в Unity, Windows-билд не выполнен**. Выполнена статическая проверка структуры и синтаксиса C#; она не подтверждает совместимость Unity API, качество физики и поведение игры. Первую полноценную проверку нужно выполнить по шагам выше; при ошибках пришлите красные сообщения из Console.

Это исходная 3D-итерация: персонажи собраны из примитивов, вместо суставного ragdoll — физический импульс и наклон модели при оглушении. Нет анимационных клипов, голосовых реплик, мультиплеера или мобильного управления. Сложность меняет частоту принятия решений ботов. Точный баланс и длительность матча требуют проверки в редакторе.
