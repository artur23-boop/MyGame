# Персонажи «Зимнего двора»

![Образы персонажей](../Unity/Assets/KingOfTheHill/Art/Characters/WinterYard-Lineup.png)

Слева направо:

- **Игрок:** горчичная куртка, светлая шапка с помпоном, светлый шарф.
- **Мишка:** широкая фигура, красная куртка, меховая ушанка.
- **Санёк:** высокий силуэт, бирюзовая парка, рыжая шапка, полосатый шарф.
- **Димон:** компактный силуэт, фиолетовая куртка, тёмная шапка.

Иллюстрация сгенерирована как визуальный референс для игры. Она не является 3D-моделью, текстурным атласом, скелетом или анимацией. Игровые процедурные модели этой итерацией не заменяются. Следующий этап для соответствия этим образам — моделирование, UV/текстуры, риг и привязка к игровым анимациям/ragdoll.
